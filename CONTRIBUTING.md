# Contributing to PauseQuest

Thanks for your interest in contributing! Please follow these steps to get your changes merged:

1. Fork the repository and clone your fork.
2. Create a new branch for your change: git checkout -b feat/short-description
3. Install dependencies and run the app locally.
4. Write tests for any new features or bug fixes.
5. Run linters and formatters: npm run lint && npm run format
6. Commit with clear messages and open a pull request to the main repository.

PR checklist:
- [ ] I have read the CONTRIBUTING.md and CODE_OF_CONDUCT.md
- [ ] My code follows the project's style guidelines
- [ ] I added tests for my changes, where applicable
- [ ] All existing tests pass

Thank you for contributing!
